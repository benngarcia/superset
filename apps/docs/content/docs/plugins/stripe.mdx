Trace charges and subscriptions, read billing data, and search Stripe's docs. Tools come from Stripe's MCP server.

| Skill | What it does |
|:------|:-------------|
| `trace-a-payment` | Answers questions about money that already moved: why a charge failed, what a customer paid, where a payout is |
| `refund-and-dispute` | Refunds a customer or responds to a dispute, with checks before each write that cannot be undone |
| `build-a-stripe-integration` | Writes Stripe code against the current API, checking every parameter in Stripe's docs |

Skills are named `stripe-<skill>`. In Claude Code they appear as `superset:stripe-<skill>`.
