Debug with production error context: search issues, read stack traces, and manage alerts. Tools come from Sentry's MCP server.

| Skill | What it does |
|:------|:-------------|
| `debug-with-sentry` | Finds the root cause of a production error from the stack trace and breadcrumbs before it changes code |
| `find-in-sentry` | Answers "what's breaking" by finding the right project and searching issues and events |

Skills are named `sentry-<skill>`. In Claude Code they appear as `superset:sentry-<skill>`.
