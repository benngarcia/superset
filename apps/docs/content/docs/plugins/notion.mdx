Search, read, and write pages, databases, and comments. Tools come from Notion's MCP server.

| Skill | What it does |
|:------|:-------------|
| `find-in-notion` | Searches Notion before the agent answers or writes, finds the current page, and cites it |
| `write-to-notion` | Writes a page under the right parent, checks for an existing page first, and structures it so people can find it |

Skills are named `notion-<skill>`. In Claude Code they appear as `superset:notion-<skill>`.
